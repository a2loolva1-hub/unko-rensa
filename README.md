# うんこ連鎖オンライン

同じ色のうんこを4つ以上くっつけて流す、漫画風の落ちものパズルです。スマホで2人オンライン対戦できます。

![うんこ連鎖オンライン](ogp.png)

## あそびかた

1. ニックネームを入れて、キャラ（まほう少女・まほう少年・ハゲのおっさん・ウンコマン）を選ぶ
2. 相手と同じ「ルーム名」を入れて「ルームに入る」
3. 2人とも「準備OK」を押すとスタート
4. 連鎖すると相手にカチカチうんこ（おじゃま）が降る

ひとりで練習もできます。

### 操作

- スマホ：画面下のボタン（◀ ▼ ▶ ↺ ↻）
- パソコン：← → 移動、↓ 落とす、Z・X（↑）回転

## しくみ

- `index.html` 1枚だけで動きます（サーバー不要）
- オンライン対戦は [PeerJS](https://peerjs.com/) の無料サーバーで相手を見つけ、端末どうしで直接通信します
